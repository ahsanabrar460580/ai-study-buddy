# 🧠 AI Study Buddy

> **Study Smarter, Not Harder with AI. 🚀**

AI Study Buddy is an AI-powered learning platform designed to make studying smarter, easier, and more personalized. Students can upload PDFs or study notes, and the platform uses AI to generate summaries, important notes, quizzes, flashcards, and simple explanations of difficult topics.

## ✨ Features

* 📄 **PDF Upload & Analysis** — Upload study materials and analyze their content.
* 🤖 **AI Notes & Summaries** — Generate important notes and concise summaries.
* ❓ **AI Quiz Generator** — Create quizzes automatically from study material.
* 💡 **Easy Topic Explanation** — Get difficult topics explained in simple language.
* 📈 **Progress Dashboard** — Track learning progress and study activities.
* 📅 **Smart Study Planner** — Organize study sessions and preparation.
* 🗣️ **Urdu & English Support** — Learn comfortably in both languages.
* 🃏 **Flashcards** — Create flashcards for quick revision.
* ⏰ **Exam Countdown** — Keep track of upcoming exams.

## 🎯 Problem

Students often spend a lot of time reading lengthy books, creating notes, preparing questions, and revising difficult topics. Managing all these tasks manually can make exam preparation difficult and time-consuming.

## 💡 Solution

AI Study Buddy brings these study activities into one platform. It uses AI to analyze study material, generate useful learning resources, explain difficult concepts, and help students organize their preparation.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/ai-study-buddy.git
```

### 2. Navigate to the Project

```bash
cd ai-study-buddy
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the root directory and add your Firebase and AI API configuration.

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id

VITE_AI_API_KEY=your_ai_api_key
```

> ⚠️ Never upload your `.env` file or private API keys to GitHub.

### 5. Run the Project

```bash
npm run dev
```

The application will start on your local development server.
